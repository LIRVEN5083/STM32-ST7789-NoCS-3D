| Display Pin | STM32F411 Pin | Description |
| :---: | :---: | :--- |
| **GND** | GND | Ground |
| **VCC** | 3.3V | Power Supply |
| **SCL** | PA5 | SPI1 Clock (SCK) |
| **SDA** | PA7 | SPI1 Data (MOSI) |
| **RES** | PA0 | Reset |
| **DC** | PA1 | Data / Command Selection |
| **BLK** | PA2 | Backlight Control |

---

| Stick Pin | STM32F411 Pin | Description |
| :---: | :---: | :--- |
| **GND** | GND | Ground |
| **5V** | 5V | Power Supply |
| **VRx** | PB0 | X coord |
| **XRy** | PB1 | Y coord |
| **SW** | PB10 | Button |
